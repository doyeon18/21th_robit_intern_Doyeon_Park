# 색상 기반 객체 인식

## 사용 기법과 선택 이유

### 1. Gaussian Blur

`cv::GaussianBlur()`를 사용해 이미지 표면의 작은 무늬와 픽셀 단위의
노이즈를 완화했다. 색상 마스크에 작은 점이 많이 생기는 현상을 줄이기
위해 HSV 변환 전에 적용했다.

### 2. HSV 색 공간

OpenCV로 읽은 BGR 이미지를 `cv::cvtColor()`를 이용해 HSV로 변환했다.
HSV는 색상(H), 채도(S), 밝기(V)가 분리되어 있어 BGR 값으로 직접
분류하는 것보다 목표 색상의 범위를 정하기 쉽다. 또한 S와 V의 하한을
설정하면 회색 배경이나 어두운 그림자가 객체로 인식되는 것을 줄일 수
있다.

### 3. inRange를 이용한 색상 마스크

`cv::inRange()`를 사용해 각 HSV 범위 안에 있는 픽셀만 흰색으로 표시한
이진 마스크를 만들었다. 사용한 범위는 아래와 같다.

| 대상 | HSV 하한 | HSV 상한 |
|---|---:|---:|
| 빨강 1 | (0, 90, 60) | (10, 255, 255) |
| 빨강 2 | (170, 90, 60) | (179, 255, 255) |
| 파랑 | (100, 90, 50) | (115, 255, 255) |
| 초록 | (45, 80, 30) | (75, 255, 255) |

OpenCV의 Hue는 0부터 179까지이며 빨간색이 이 범위의 시작과 끝에
나뉘어 있다. 따라서 빨간색 마스크 두 개를 만든 뒤 `cv::bitwise_or()`로
합쳤다. 위 범위는 과제용 `input.png`에서 세 객체가 각각 한 번씩
검출되도록 직접 확인한 값이다.

### 4. 형태학 연산

5x5 타원형 커널로 Opening과 Closing을 차례로 적용했다. Opening은
마스크 바깥의 작은 흰색 노이즈를 제거하기 위해 사용했고, Closing은
객체 내부의 작은 검은색 구멍을 메우기 위해 사용했다.

### 5. 윤곽선과 바운딩 박스

`cv::findContours()`의 `RETR_EXTERNAL` 옵션으로 마스크의 바깥쪽
윤곽선만 찾았다. 작은 노이즈가 객체로 표시되지 않도록 면적이 2000
미만인 윤곽선은 제외했다. 남은 윤곽선에 `cv::boundingRect()`를 적용해
사각형을 구하고, 빨간 객체에는 빨간 박스, 파란 객체에는 파란 박스,
초록 객체에는 초록 박스를 표시했다.

## 프로그램 처리 순서

1. 상대경로 `input.png`에서 이미지 읽기
2. Gaussian Blur 적용
3. BGR 이미지를 HSV로 변환
4. 빨강, 파랑, 초록 마스크 생성
5. Opening과 Closing으로 마스크 정리
6. 윤곽선 및 바운딩 박스 계산
7. 결과를 `result.png`로 저장

## 빌드 및 실행

프로젝트 최상위 폴더에서 다음 명령을 실행한다.

```bash
cmake -S . -B build
cmake --build build
./build/color_detector
```

입력 파일은 프로젝트 폴더의 `input.png`이며, 실행 결과는 같은 폴더의
`result.png`에 저장된다. 다른 이미지를 시험하려면 입력 및 출력 경로를
인자로 전달할 수 있다.

```bash
./build/color_detector 다른이미지.png 다른결과.png
```
