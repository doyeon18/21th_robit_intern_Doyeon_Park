# 강화학습 3일차 실습 보고서 
## DQN 모델 평가와 학습률 변경 실험


### 1. 모델 저장·재로딩과 평가 

학습이 끝난 Online Network의 state_dict를 .pt 파일에 저장했다. 이후 같은 구조의 신경망을 새로 만들고 가중치를 불러왔다. 모델 파일 생성은 저장 성공을 의미하며, 제어 성능은 별도 평가로 확인했다.

최종 평가는 환경 seed 1000~1049에서 총 50회 수행했다. 탐험률은 0으로 두고 Q 값이 가장 큰 행동만 선택했으며, 평가 중 파라미터를 갱신하지 않았다. 

CartPole 보상이 매 스텝 1이므로 에피소드 보상 합은 실행 스텝 수와 같다. 평가 지표는 비할인 보상 합의 평균·표준편차·최솟값·최댓값으로 정했다. 시간 제한 500스텝에 도달한 경우와 실패 종료를 구분하고, 실패 시 카트 위치와 막대 각도를 기록했다.

### 2. 실험 설정

| 항목 | 설정 |
|---|---|
| 실행 환경 | Ubuntu, CPU, Python 3.12.3 |
| 신경망 | Linear(4,64) → ReLU → Linear(64,64) → ReLU → Linear(64,2) |
| Optimizer | Adam |
| 기본 / 변경 학습률 | 0.0005 / 0.001 |
| 할인율 | 0.99 |
| Replay Buffer / batch | 20,000 / 64 |
| 본 루프 학습 시작 | 저장된 경험 1,000개 이상 |
| Online / Target 갱신 | 환경 4스텝 / 500스텝마다 |
| 학습 예산 | 환경 40,000스텝 |
| 탐험률 | 15,000스텝에 걸쳐 1.0 → 0.05, 이후 유지 |
| 손실 함수 / gradient norm 제한 | SmoothL1Loss / 10 |
| 학습 seed | Python·NumPy·PyTorch·환경·행동 공간 0 |

현재 학습 루프 전에 무작위 경험 64개 수집과 초기 업데이트 1회가 포함되어 있다. 이 조건은 두 학습률 실험에서 동일하게 유지했으며, 본 루프 이전 업데이트의 loss는 그래프 기록에 포함하지 않았다.

### 3. 결과 비교 

무작위 정책은 매 스텝 왼쪽·오른쪽 중 하나를 무작위로 선택했다. DQN과 같은 초기 상태 seed 목록에서 50회 평가하였으며, 무작위 행동 공간 seed는 0으로 설정했다.

설정 변경 실험에서는 학습 seed와 다른 하이퍼파라미터를 유지하고 Adam 학습률만 0.0005에서 0.001로 높였다.

| 정책 | 평균 | 표준편차 | 최소 | 최대 |
|---|---:|---:|---:|---:|
| 무작위 정책 | 26.12 | 15.78 | 10 | 82 |
| 기본 DQN, lr=0.0005 | 168.72 | 45.59 | 100 | 277 |
| 변경 DQN, lr=0.001 | 184.02 | 13.04 | 157 | 218 |

기본 DQN은 무작위 정책보다 평균 약 6.46배 오래 버텼다. 경험에 따른 가치 학습이 무작위 행동보다 좋은 제어 결과로 이어졌음을 볼 수 있었다.

학습률을 두 배로 높인 실행에서는 평균 보상이 15.30점, 약 9.1% 증가했다. 최소 점수는 높아지고 평가 에피소드 간 표준편차는 감소했지만 최대 점수는 낮아졌다.

학습률 증가는 optimizer가 계산하는 파라미터 수정 크기에 영향을 주며, 이후 수집되는 경험도 달라질 수 있다. 이번 결과는 그 과정을 거친 최종 모델의 차이로 볼 수 있다. 다만 한 학습 seed에서의 비교이므로 증가한 학습률이 일반적으로 더 좋다는 결론은 내릴순 없다.

### 4. 실패 분석

기본 모델에서는 막대 각도 초과와 카트 위치 초과가 모두 발생했다. 카트 위치로 실패한 경우는 왼쪽 경계 약 -2.4m를 벗어났고, 각도로 실패한 경우는 양의 약 12도를 초과했다.

변경 모델은 50회 모두 카트가 오른쪽 경계 약 +2.4m를 넘어 종료됐다. 이때 막대 각도는 약 +4.8~+5.7도로 각도 한계 이내였다. 따라서 변경 모델에서도 카트가 위치 한계에 도달하는 것을 방지하는 제어는 충분하지 않았다.

### 5. 학습 과정 시각화와 해석

다음 네 그래프를 각 학습률의 기록으로 생성했다.

| 그래프 | 표시 | 확인 목적 |
|---|---|---|
| 학습 보상 | 에피소드별 보상과 20에피소드 이동 평균 | 탐험을 포함한 학습 성능 변화 |
| Greedy 평가 보상 | 환경 스텝별 10회 평균 ± 표준편차 | 탐험을 제외한 제어 성능 |
| TD loss | 업데이트별 loss와 100업데이트 이동 평균 | 예측과 학습 목표의 오차 변화 |
| 탐험률 ε | 환경 스텝별 ε | 탐험 일정 적용 여부 |

학습률 0.001의 중간 평가 평균은 6,000스텝에서 263.10점, 마지막 40,000스텝에서는 194.20점이었다. 성능이 계속 증가하지 않고 학습 과정에서 변동했음을 확인했다. 중간에 최종 모델보다 높은 성능을 보인 시점도 있었다.

학습 보상에는 무작위 탐험 행동이 포함돼 있으므로 greedy 평가와 구분해서 해석했다. TD target 역시 학습 과정에서 바뀌므로 loss 크기만으로 제어 성능을 판단하지 않았다. 중간 평가는 10회, 최종 평가는 50회로 평가 횟수가 다르므로 두 수치를 구분했다.

### 6. 내용 설명

TD target은 다음 식으로 계산한다.

`y = r + gamma × (1 - d) × max Q_target(s′, a′)`

보상 r=1, 할인율 gamma=0.99, 다음 상태의 최대 Q 값=10일 때:

- 일반 전이: y = 1 + 0.99 × 10 = 10.9
- 실패 종료: d=1이므로 y = 1
- 외부 시간 제한: d=0으로 처리하여 y = 10.9

Replay Buffer는 경험을 저장하고 무작위 batch로 재사용한다. 연속 경험 사이의 상관을 줄이고 과거 경험을 다시 학습하는 역할을 한다.

Target Network는 목표 계산용 파라미터를 일정 기간 고정한다. Online 업데이트마다 목표 계산용 네트워크까지 즉시 바뀌는 현상을 완화하며, 500스텝마다 Online 가중치를 복사해 갱신한다. 두 기법은 학습 안정화에 도움을 주는 방법이다.
